\caption{\sys. A harness is a chain of skills (instruction text with optional examples), shared tools and deterministic rule steps. One round annotates a gold document, attributes each divergence from gold to the responsible skill and scheme category, and edits those skills (orange borders). The next document is annotated by the new harness before it is used to improve it.}
