## 1. 新的故事（一句话版与摘要骨架）

**一句话：** UMR 是一种覆盖面很广的语义表示，它的标注难在大量约定、外部词汇资源和文档层关系。我们让 LLM 只从 guideline 和 50 个 gold 句子出发学会 UMR parsing，结果超过共享任务里经过微调的系统。我们把提升逐项追溯到具体改动，并说明哪些 UMR 层能用这种方式学会、哪些学不会。

**题目候选：**
- *Learning to Parse Uniform Meaning Representation from Its Guideline and Fifty Sentences*
- *What Does an LLM Need to Learn to Parse UMR? Self-Refining an Annotator from the Guideline*

**摘要骨架（5 句）：**
1. UMR 把概念图、PropBank 词义、aspect、modality、指称属性和文档层的时间、模态、共指关系统一在一个表示里，适用于多种语言；大多数语言的标注数据很少，微调 parser 效果有限（共享任务最好的系统在我们的测试文档上中文 37.7、英文 40.3 AnCast++ F）。
2. 只把 guideline 交给 LLM 也不够：我们的诊断显示，失分主要来自 guideline 与数据约定不一致、PropBank 词义和论元，以及文档层关系。
3. 方法：先从 guideline 写出分步的标注器，再在 10×5 个 gold 句子上由 LLM 逐轮找错、修改说明、写查询 PropBank 的工具和规则代码。
4. 结果：中文 +6.1、英文 +11.3 F，官方 juːmæʧ 42.9 / 38.0，超过微调系统（38.8 / 27.3）。
5. 归因：提升来自哪类改动、落在哪一层（约定和 notation、PropBank 查询、文档层 modal）；aspect、时间和共指几乎没有提升，原因是缺少可查的资源、gold 本身不一致。最后讨论这对 UMR 标注项目意味着什么。

### §1 Introduction（约 1 页）

- **P1 UMR 是什么，为什么重要。** UMR 在 AMR 基础上加上了 aspect、modality、指称属性（person、number）、文档层的时间、模态、共指，以及词对齐；而且面向多种语言（包括没有 PropBank 的语言）。它提供了一种跨语言、跨句子的统一语义表示。[有：引用 vangysel2021、bonn2024]
- **P2 难点：标注复杂，数据稀少。** guideline 36.6 万字符，需要外部资源（中英文 PropBank）。大多数语言的 gold 很少，英文发布数据也多是 AMR 的部分转换。所以第一届 UMR parsing 共享任务的微调系统效果有限：在我们的测试文档上 Orange 中文 37.7、英文 40.3 F。[有]
- **P3 自然的想法是让 LLM 读 guideline，但这不够。** 用数字说明：Haiku 读整篇 guideline，中文 30.9 F、官方 juːmæʧ 12.5。点出 RQ1 的发现：失分主要不在"理解"，而在约定、资源和文档层（§4 的结论提前讲）。[有 + 析]
- **P4 方法一段话。** 从 guideline 写出分步标注器，再用 50 个 gold 句子逐轮自我修改：改说明、写 PropBank 查询工具、写规则代码。和 Kim et al. 2026 的区别在于：他们做 flat NER，只改 guideline 文本；我们面对的是一个多层的图表示，改的是说明、工具和代码。[有]
- **P5 主要结果加归因的一句话。** +6.1 / +11.3 F，juːmæʧ 超过微调系统；提升集中在约定、词义和论元、文档层 modal，aspect、时间、共指不动。
- **P6 贡献（写成发现，不写成"我们提出一个框架"）。**
  1. 对 LLM 做 UMR parsing 的按层诊断：guideline 与数据之间的差距是可以测量的（§4）。
  2. 只用 50 个 gold 句子、不微调，超过共享任务的微调系统（§6）。
  3. 把每项提升追溯到具体改动和 UMR 层，并展示改动前后的说明（§7）。
  4. 学不会的东西以及原因，对 UMR 标注项目的建议（§8）。

### §2 UMR：它表示什么，为什么难 parse（约 1.5 页）

这一节回答"UMR 解决了什么问题"和"这个标注足够复杂、全面"。每一层都讲三件事：表示什么（相对 AMR 新增了什么）、parse 时难在哪、用哪个 judge check 评。

- **2.1 UMR 解决了 AMR 的哪些问题**
  - P1 AMR 的局限：以英语为中心，没有 tense/aspect，modality 只有 polarity 等，只表示单句，没有对齐。
  - P2 UMR 的回应：跨语言设计（没有 frame 的语言用 `lemma-00` 加 `:actor`/`:undergoer`）、aspect、modal strength 和文档层 modal 依存、时间依存、跨句共指、指称属性、词对齐。用一个中文例句画出句子图加文档层（图 1，替换现在的 overview 图，或者并列）。
- **2.2 句子层**
  - P1 概念和粒度：事件还是实体；中文概念要写中文词，不翻译；分词和粒度（`a_granularity`）。
  - P2 PropBank 词义和论元：要查外部 frame；没有 frame 时用 `-00` 加 `:actor`/`:undergoer`（`b_event_sense`，`d_core_args_*`，`e_core_labels`）。
  - P3 属性：aspect（state、activity、performance……）、polarity、refer-person 和 refer-number、mode 等（`c_*`）。
  - P4 名称、wiki、重入（`f_*`，`g_reentrancy`）。
- **2.3 文档层**
  - P1 时间依存（`h_temporal`）、模态依存（`i_modal`）、共指（`j_coref_*`）、格式（`k_doc_format`）。
  - P2 文档层为什么特别难：要看前文，关系要指向前面句子里的变量，gold 稀疏。
- **2.4 中文 UMR 的特殊性**
  - P1 中文 PropBank、中文概念、量词和体标记（了、着、过），以及中英文 gold 来源的差异。
- **2.5 数据和已有系统**
  - P1 共享任务（stepanek2026）和 UMR 2.2；英文完整标注的训练文档只有 3 篇；Orange、Sema 两个微调系统。

### §5 方法：从 guideline 到可以自我修改的标注器（约 1.25 页）

  - P1 学习顺序是 notation → 文档层 → 语义（英文轨迹：第 1 轮 notation，第 2–6 轮文档层，第 7–10 轮语义）。50 句 gold 主要教会的是项目约定和查资源的方法。
