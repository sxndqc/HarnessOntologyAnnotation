\section*{Limitations}
\label{sec:limitations}

\paragraph{Scale and variance.} The complete results are on one scheme and language, Chinese UMR, with \nDocs{} documents and \nSentences{} sentences in the sequential run; three documents have only 10--12 sentences. Each configuration was run once, in one document order; we report paired tests over documents and a sentence-level bootstrap, but not run-to-run variance of building or annotating \gap{G-var}.

\paragraph{No test before keeping an edit.} \sys keeps every edit that applies cleanly; its quality is measured only on the next document. Methods that test edits on held-in data may avoid some of the failure modes we report, and we have not compared them \gap{G9}.

\paragraph{Human influence.} The seed harness, the judge's checks and the builder's prompts were written by the authors, and one rule step was changed by hand during the run (\S\ref{sec:harness}). The suggestions in \S\ref{sec:analysis} were coded by one person.

\paragraph{Models.} The main run uses one closed model family for both annotating and building. Results with other models (Table~\ref{tab:models}) use a different harness and fewer documents, and DeepSeek ran without thinking.

\paragraph{Data.} The leakage guard filters exact eight-character overlaps, not paraphrase, copying of shorter spans or document-specific knowledge. It consults held-out source sentences for rejection and can therefore provide an indirect constraint on training edits. API versions and runtime defaults may change, and exact historical backend, effort and cache settings must be audited before reproduction. The source texts of the documents may appear in pretraining data; \gap{state whether the Chinese UMR gold is public}. Gold conventions differ between documents (\S\ref{sec:analysis}), which bounds what any learner can reach.

\section*{Ethics Statement}
Automating annotation can reduce the paid work available to annotators. We see the learned harness as a way to produce drafts and to audit gold, with people deciding conventions; its suggestions about inconsistent gold are addressed to them. Model calls use commercial APIs or open-weight deployments. \gap{Verify the exact data release, license, permitted API use and redistribution terms; identify what source text and gold were sent to each service.} We do not infer those permissions from the presence of a local data checkout.

Generative AI assisted author-side simulated review and manuscript editing. It did not supply new experimental results; this assistance is not formal ARR peer review.
