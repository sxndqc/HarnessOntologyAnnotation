\section{Related Work}
\label{sec:related}

\paragraph{LLMs as annotators, guidelines as input.}
LLMs can replace or assist crowd workers on many labeling tasks \citep{wang2021want,gilardi2023chatgpt,he2024annollm,ziems2024can,tan2024large}, but they follow a scheme's conventions poorly out of the box: as AMR analyzers \citep{ettinger2023you}, as annotators of document-level event relations \citep{wei2024llms}, and with real codebooks, whose underspecified concepts they silently accept \citep{halterman2026codebook,halterman2026what}; they help experts more than they replace them \citep{gu2026large}. Guidelines help when models are trained to follow them \citep{sainz2024gollie,srivastava2025instruction} or replace examples in context \citep{huang2025guidener}. Guidelines can also be learned: Guideline Learning induces rules from errors \citep{pang2023guideline}, in the tradition of error-driven rule learning \citep{brill1995transformation}; LLMs revise annotation guidelines against gold \citep{bibal2025automating,kim2025repurposing}, and \citet{kim2026refining} let a moderator model write one principle at a time into an NER guideline and keep it when development F1 improves, while \citet{kim2026diziner} refine NER instructions from the disagreements of several LLM annotators. Codebook work revises coding instructions from expert feedback or model disagreement \citep{he2026experts,yuan2026calico}. These methods change instruction text for flat labeling tasks. Structured schemes such as UMR and TimeML are annotated by trained parsers when data exist \citep{chun2024pipeline,markle2026setup,bethard2013cleartk,heinecke2026orange}, by converting other resources \citep{gamba2025bootstrapping}, or by people revising model drafts \citep{sun2024chinese}; we bootstrap them from the guideline and a few examples, and the object we change is the whole harness.

\paragraph{RSI, prompt optimization, self-improving agents and harnesses.}
Systems that improve the code that improves them go back to the Gödel machine \citep{schmidhuber2003goedel}; with LLMs, a model can improve its own scaffolding \citep{zelikman2024self}, an agent can rewrite its own logic \citep{yin2025godel}, and archives of self-modified agents can be searched \citep{zhang2026darwin,novikov2025alphaevolve}. Prompts can be searched and evolved \citep{zhou2023large,yang2024large,fernando2024promptbreeder,guo2024connecting}, edited along textual ``gradients'' or execution traces \citep{pryzant2023automatic,yuksekgonul2025optimizing,cheng2024trace}, compiled with demonstrations \citep{khattab2024dspy,opsahlong2024optimizing}, evolved by reflection \citep{agrawal2026gepa}, or grown as playbooks \citep{zhang2026agentic,suzgun2026dynamic}; with little data they can lose to fixed prompts \citep{singh2026mage}. Agents also learn skills \citep{wang2024voyager,zheng2025skillweaver}, make tools \citep{cai2024large,qian2023creator,yuan2024craft,wang2024trove}, and search over workflows \citep{hu2025automated,zhang2025aflow,zhuge2024gptswarm}. Recent work optimizes the harness of coding and web agents itself \citep{lee2026metaharness,zhang2026self,lin2026agentic,xia2026regularized}, and finds that gains compound only with regression control \citep{wang2026do} and that writing useful updates and benefiting from them dissociate across model tiers \citep{lin2026harness}. Self-feedback rarely helps without an external signal \citep{madaan2023selfrefine,shinn2023reflexion,huang2024large,kamoi2024when}. We bring this line of work to annotation, where gold is scarce but structured: an aligned gold annotation and a judge that sorts each error into a part of the scheme give the builder far more than a pass/fail reward, and the improvement loop plays the role of the moderation step of a human annotation project \citep{pustejovsky2012natural}.
