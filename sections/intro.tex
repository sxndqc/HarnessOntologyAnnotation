\section{Introduction}
\label{sec:intro}

Many language-processing projects begin by committing to an ontology, a scheme of labels, relations and conventions, and annotating data with it: Uniform Meaning Representation (UMR) graphs for cross-lingual semantics \citep{vangysel2021designing,bonn2024building}, TimeML for temporal structure \citep{pustejovsky2003timeml}, codebooks for political text \citep{lehmann2026manifesto}. People are trained on the guideline for weeks, and one document can take hours; for Chinese UMR, even revising GPT-4 drafts saved about two thirds of the time \citep{sun2024chinese}.

LLMs recover who did what to whom without training. What they lack is the scheme: its labels, its conventions where it departs from intuition, the resources it points to. Supplying this is the job of the \emph{harness} around the model: the instructions of each step, the tools a step can call, the chain of calls, and deterministic code that keeps the output well formed. Harnesses are built the way guidelines are: a person annotates a document with the current harness, compares it with gold, decides which component is at fault, edits it, and repeats. This loop decides how good the annotator is, and it is the expensive part.

We ask whether the model can run the loop itself: \emph{given a few gold documents and a seed harness that a person could write in an afternoon, can an LLM build a better annotator?} Earlier work has LLMs revise annotation guidelines against gold for biomedical entity recognition \citep{kim2026refining}; it starts from a detailed human guideline, targets one error pattern per iteration, rewrites the guideline text, and has no place for tools or steps. Self-improving agents optimize prompts, workflows and code against task rewards on agentic and reasoning benchmarks \citep{zhang2026self,hu2025automated}. Annotation offers a richer signal than either: gold is a structure that can be aligned with the prediction, so each divergence can be traced to a place in the harness. The difficulties are credit assignment over hundreds of divergences per document, knowledge that belongs in code or lookups rather than prose, a builder that runs its own code and can copy gold, and honest measurement when every annotated document is precious.

We present \sys (Figure~\ref{fig:overview}). After annotating a gold document it records a trace of every step, attributes each divergence to the responsible skill and scheme category, applies typed edits (modify, add, delete) to that skill only, admits new tools and steps only through machine checks and a reviewer, and rejects edits that copy gold text. We measure it test-then-train: each document is annotated by the harness built from the documents before it, and the seed harness annotating the same document is the paired control.
