Changes, by cost in the critique:

1. **Temporal anchoring.**
   - When an aspectual verb takes an event, the inner event is the anchor.
   - Every other event links to the anchor; only the anchor links to the document creation time.
   - A process nominal that is a verb's argument takes `:overlap` with that verb.
   - For present-situation main events, `:depends-on` is now a firm rule instead of "often".
2. **Participants.**
   - "Fill only what the syntax provides" now also covers dropped subjects and objects of finite clauses.
   - New rule for the relative clause headed by an aspectual verb.
   - Partitives are `:mod`; only closed-list roles are allowed.
   - Read the roleset for belong-type verbs.
3. **Fused negation (未经-type).** Use the un-negated verb's PropBank sense, roles and aspect (`process` for 经-type verbs). Nested events get `partial-affirmative`. The "[event] procedure" compound uses `identity-91`.
4. **Aspect.** Rule 2 now applies only to aspectual verbs taking an event complement. Lexical verbs of ending are `performance`. State verbs stay `state` with 过 or 曾经.
5. **Names.** No `:wiki` in Chinese documents; periodicals are `newspaper`.
6. **Degree and history phrases.** A superlative over a verb puts that verb as `:ARG2` of `have-degree-91`. `have-degree-91` gets no modal link. "In X's history" phrases use a postposition `:temporal`, with the place rule applied to abstract nouns too.
7. **Small fixes.** 曾经 is `:temporal`. Mixed-separator coordination is nested. Only tracked discourse entities are coreferenced.
