I made these choices:

- **Senses:** I looked both verbs up in Chinese PropBank. 称呼-01 and 称为-01 each have the roles ARG0 (the namer), ARG1 (the thing named) and ARG2 (the name).
- **The unstated object:** In the second clause, the thing China names is left out. It is the same 核废水 as in the first clause, so I reused that node (`:ARG1 s6h`) instead of adding a new one.
- **The two names:** 处理水 and 核污染水 are each one word in the sentence, so I kept each as a single concept and did not split them into parts like 处理-02 or 污染-01.
- **Joining the clauses:** Only a comma links them. I used `and`. `contrast-91` would also be defensible, since the sentence sets the two names against each other.
- **Aspect:** I marked both naming events `habitual`, meaning each country keeps using its name. This was a close call, and `state` would also be reasonable.
