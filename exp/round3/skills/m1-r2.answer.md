- Temporal direction: (A :before B) means A is before B; (A :after B) means A is after B. Past events: (document-creation-time :before E). Earlier event as child of later is wrong; read the triple aloud "parent is before/after child". Dates: date-entity :contained the event, and DCT :before the date-entity (not the event twice). Planned/complement events under 计划/申请 are :after the governing predicate only if truly future; same-time purposes/complements (改为, 转型, 加入 under 计划/申请) are :overlap.
- Temporal parents for background states/habituals: chain to the nearest governing event (e.g. 广播 :overlap 设有; 收费 :overlap 广播; 制作 :overlap 担任), not always DCT. Copular identity-91 also needs its own temporal (and modal) parent; give it :overlap DCT or the preceding sentence's state.
- Every event node, including identity-91, have-rel-role-92, have-org-role-92, but-91, 旗下/华裔-type predicates, 用于/用以/位于/组成, 达到, 遭到, 隔, 服务, 属, needs a modal parent (author :full-affirmative by default). Negated (达不到, 未能, 无意) → polarity "-" on the base event (达到, not 达不到) with :full-negative.
- Predicate concepts: use the plain word + sense number, never bare ("空袭-01", "救援-01", "裁决-01", "提早-01", "武装-01", "行动-01", "收费-01", "处于-01", "限于-02", "属-02", "介乎-01", "自制-01", "定下-01", "斥资-01", "守节-01", "要求-01" not -02). Use the core verb, not the compound: 批 (not 批予/批准), 售 (not 售予), 设 (not 设有), 调往, 现存, 放上, 达到, 作出, 致力于, 简称. Never leave a word unsensed; if not in PropBank still add -01.
- Causal/reason: 因为/由于/所以 → have-reason-91 vs have-cause-91 per gold (致使 → have-cause-91; 因此/导致 → :cause); 虽然…但, 然而 → but-91 / contrast-91 (and-contrast, and-but for 而/则 contrasts) rather than plain and. Conjunctions: use and / or (或) / and-contrast; do not use "and-91".
- Entity types: use fine UMR types, never generic "organization"/"person"/"local-region"/"thing": company (电视, 集团, 公司), government-organization (CRTC, 天文台, 当局), international-organization (UN bodies, 世界中央厨房, UNRWA, OCHA), armed-organization (以军, 哈马斯, 国防军), individual-person for named people, country-region (中国大陆, 台湾, 加东/加西, regions), country, city, district, province, village/town, nationality, show (TV program), broadcast-program only when gold uses it. Common-noun concepts keep the head word (节目 not 电视节目; 电视 not 宽带电视; 情况 not 极端情况; 少数族裔 → 族裔 + mod 少数; 洪水); modifiers become :mod (宽带, 卫星, 有线, 极端, 扶手, 主, 该, 收费, 地区性, 全国性).
- Names: one :opN per word, only the name itself (not 公司/市/镇/村/县/地带 suffix unless part of the official name; 《》 titles keep the brackets as ops; keep 间隔号). Don't add names to repeated 该台/城市电视 refs—use the same variable. Names like 国民政府/北洋政府: 政府 concept with :mod 北洋, not a name node.
- Quantities: :quant digit and :unit classifier for every counted noun (座/种/辆/次/批/名/个/条/项/套/天/公里/米/公吨/港元); never put the classifier as an attribute string; numbers digits only; times of day as one string or date-entity not attribute; coordinates as geographical-coordinate-entity with numeric values; "每/各" → :quant 每 / :mod; ordinals :ord (ordinal-entity).
- Role labels: use :medium for languages/channels/systems (以普通话广播, 语言 :medium-of 服务, 宽带电视系统); :manner for adverbs (一直, 立刻, 全面, 一致, 直接, 误); :temporal for time words (不久, 同年, 内, 前/后 as before/after with :op1 event); :mod for adjective-like modifiers and 亦/均/曾/更/已/仍/还/几乎; :unit for classifiers; :place for locations (本地, 全国); :part / :part-of for part-whole (港口 part-of 地带); :extent for distances; :path for 路线; :goal for 前往/运至 destination; :source for 来自/购自.
- Core args: follow PropBank roles exactly; passives and unaccusatives (身亡, 受伤) → ARG1 the patient, 导致/致使 → have-cause-91 ARG1 cause ARG2 effect per gold; 有 (exist) → 有-01 or exist-91 as gold; 位于/设于 :ARG1 thing :ARG2 place. Include every arg: agent (arg0 company for 加入/播放/限于), the object (资产, 牌照, 粮食), and implicit ones from coordination; don't drop the real object for a nominal.
- Aspect: completed past events (申请, 批准, 宣布, 袭击, 启播, 改组) → performance; ongoing plans/process (计划, 转型 plan) → endeavor/process per gold; habitual for recurring practices; states for descriptive/copular/identity predicates and existential; activity for 正在/开始 ongoing.
- Coreference: link every repeated entity/event mention (organizations like 世界中央厨房, 政府, 空袭, 遗体, 爆发, 粮食; cities) to the nearest earlier mention; use :subset-of for partial reference (牌坊 in a later sentence → 牌坊 in sentence 1). Never link name nodes or distinct events.
- Don't invent extra nodes: no extra :purpose/:mod/:possessor for relations the sentence does not state; drop :possessor for 该台 when reentrancy with the same entity suffices; keep 该/各/原/等/最/更 as appropriate.
