## Points

- Entity types: use specific guideline types, not generic `organization`/`person`: company (TV stations, firms), government-organization (CRTC, 当局, 文物局), international-organization, armed-organization, individual-person (named people), country-region (China, Taiwan, mainland), nationality, broadcast-program (named shows, 频道), geographical-coordinate-entity. Never `name`, `after`/`before` for 后/前 (use `:temporal` on the noun 后/前 only as the guideline says).
- Do not fuse words into one concept: 宽带电视→电视 + `:mod 宽带`; 少数族裔→族裔 + `:mod 少数`; 电视节目→节目 + `:mod 电视`; 贞孝节烈牌坊→牌坊 with separate mods 贞孝, 节烈. Use verb stem when the suffix is a directional/light part (批予→批, 售予→售, 批准→批, 设有→设).
- Sense numbers: nominal-event/verb words in PropBank get `-01` (空袭-01, 事发-01, 救援-01, 要求-02 for "request/demand", 提早-01, 邻近-01), never bare.
- Measure words: put `:unit` on the classifier (条, 套, 座, 种, 名, 辆, 次, 公吨, 公里, 米, 项, 个, 任, 代, 批) and keep the number as `:quant`; do not put classifiers as attributes. Numeric values like 100, 240, 1.6, 31.4118 are plain attributes, not concept nodes. Times (10:00) are date-entity values, not literal attributes.
- Possession and modification: use `:possessor` (never `poss`). Use `:mod` for 同时, 本地, 地区性, 收费, 主要, 各 → `:quant`, 约 → `:quant`. Place names modifying a thing use `:place`, but kinship/part relations use `:part`/`:part-of` (南部, 港口, 各地, 上面).
- Role choices: language of broadcast → `:medium`; 标清/高清/同一讯号 manner/medium by context, never `:instrument` for media; 立刻/随即/一直 → `:manner`/`:temporal` per guideline (keep consistent); 全面/重点/真正/直接 → `:manner`; 更/曾/遂 → `:mod`.
- Names: use bare name tokens split by word, without suffix generics (柳树, 台源, 金门, 贝尔) and without quotes marks inside «» ; named titles keep 《》 as part of the name tokens. Don't make names for common nouns (大总统, 政府 alone). Don't name a name for each repeated mention unless it is a proper name.
- 是/为/即是 → identity-91; 属于/有 existential → have-... / `:arg1`/`:arg2` of the PropBank roleset. Check arg numbering with PropBank: location-holder `位于/处于` arg1 = thing, arg2 = location; 来自 arg1 thing, arg2 source; 有 as possession arg0 owner, arg1 thing; 设有 arg0 company, arg1 thing.
- Cause: 因为/由于/所以 → have-cause-91 (arg1 cause... follow the guideline), `:cause` for the cause event on the result event; never have-reason. 致使 → have-cause-91.
- Contrast: 但/虽然…但/则 → `but-91`; and-contrast → `and-but`/`contrast-91` per the guideline; use `or` for 或, `and` for 和; use `and-91` etc. only for the specific forms in the guideline.
- Aspect: habitual for generic/regular facts and customs, ongoing services, and descriptions of laws/systems (e.g. 设有 channels, 广播 coverage, 服务); performance for completed events in narrative; state for static properties; activity for ongoing/repeated unbounded; process for incremental change; endeavor for planned/attempted actions (计划, 申请 attempts) . Every event node needs an aspect; don't omit it for 得到/保证/申请 etc.
- Temporal: DCT is `:before` any past-narrated event; use `:contained` for date-entity with event only when the date is a point; `:overlap` for time spans (e.g. 申请 within a year? use `:contained` only for "in YEAR" points; keep `:overlap` for ongoing state). For 计划/plan with complement: `:overlap` (not `:after`) and modal `:unspecified`.
- Modal: every event and entity-predicate (identity-91, have-org-role-92, have-rel-role-92, 属, 简称, 华裔, 旗下, 自制) gets `author :full-affirmative` unless it is embedded under a reporting/opinion predicate (then attach to that predicate instead of author). Negated actual events: `:full-negative`.
- Coref: link repeated mentions (频道, 公司, 政府, 旌表, 制度, 牌坊 subset-of) earlier-first; keep coref across sentences for the same company/government entity.
- Core ARGs: for 申请/获批/允许 etc. put the request under ARG1 and the authority/recipient in the roleset's correct ARG; 创下/达到/高 → have-degree-91 with arg1 thing, arg2 attribute, arg3 degree word (最/新). Do not add extra arguments not in the sentence.

## Skill

- Use specific entity types: company (TV firms), government-organization (CRTC, 当局, 局), international-organization, armed-organization, individual-person (named people), country-region (China/Taiwan/mainland), nationality, broadcast-program (shows, 频道), geographical-coordinate-entity — never plain `organization`/`person`/`name`/`after`/`before`.
- Don't fuse words: 宽带电视→电视+`:mod 宽带`; 少数族裔→族裔+`:mod 少数`; 电视节目→节目+`:mod 电视`; 贞孝节烈牌坊→牌坊 with separate mods. Use the bare verb stem for 批予/批准/售予/设有 (批, 售, 设).
- Words in PropBank get a sense number (空袭-01, 事发-01, 救援-01, 提早-01, 邻近-01; 要求-02 for demand). Never bare.
- Classifiers are `:unit` nodes (条, 套, 座, 种, 名, 辆, 次, 公吨, 公里, 米, 项, 个, 代, 批) with the number as `:quant`; plain numbers/times stay attributes, not concepts or classifier attributes.
- Use `:possessor` (never `poss`); `:part` for 南部/港口/各地/上面; `:medium` for languages and channels (never `:instrument` for media); `:manner` for 全面/重点/真正/直接/立刻 adverbs; `:mod` for 更/曾/遂/本地/地区性/收费/主要.
- Names: bare tokens split by word, no generic suffix (柳树, 台源, 金门), keep 《》 in show titles; no names for common nouns (政府, 大总统).
- 是/为/即是 → identity-91. Check PropBank arguments (位于/来自/设有/有); 申请 request goes in ARG1; degree predicates (创下/高) → have-degree-91 (arg1 thing, arg2 attribute, arg3 最/新).
- 因为/由于/所以 → have-cause-91 (never have-reason); `:cause` on the result; 致使 → have-cause-91. 但/虽然 → but-91; 或 → or.
- Aspect on every event: habitual for customs, systems, regular services/coverage; performance for completed narrated events; state for static properties; activity for ongoing; process for gradual change; endeavor for attempts.
- Temporal: DCT `:before` past events; `:contained` for point dates, `:overlap` for ongoing; 计划 with complement → `:overlap` and modal `:unspecified`.
- Modal: give every event and predicate-like node (identity-91, have-org-role-92, 简称, 华裔, 旗下) `author :full-affirmative` unless under a reporting/opinion predicate; negated actual events `:full-negative`.
- Coref: link repeated mentions (频道, company, 政府, 牌坊 subset-of) to the earlier one across sentences.
