## Points

- Roleset numbers: if a word isn't in PropBank (e.g. 遇袭, 启播, 批予, 奏请, 穿着, 葬, 送院, 停驶, 获批, 撰, 旌表, 购…), write `-00`, never an invented `-01`. If PropBank has the word (限于, 处于, 来自, 位于, 迁至, 购自, 惨死, 常用, 现存, 写道, 长达, 印有), use that exact entry, not a near synonym or a split form (限-01, 迁-01, 购-01).
- Use only the arguments listed in the roleset. Single-argument predicates (不同, 身亡, 有限, 大, 低, 突然, 惨死, 行之有效, 必要, 清醒, 明显, 存活, 残留, 恢复) take `:ARG0`, never `:ARG1`. Do not invent ARG2/ARG3/ARG4 (是/为, 来自, 位于, 追溯-02, 限于, 改组, 改为, 前往, 移动, 进入, 返回). Look up the roleset before assigning numbers, and do not assign them by English intuition. If a core argument can express the relation, don't use `:place`/`:source`/`:manner`.
- Copulas 是/为/即是/为 (X is Y) create no node: use identity-91 (ARG1 theme, ARG2 equated). Equatives, appositions, and "分别是" also use identity-91. Never use 是-01, 为-01, `:domain`, or have-role-91 with ARG0.
- Titles and roles: have-org-role-92 (never -91), the person is ARG1 (`:ARG1-of`), organization ARG2, title ARG3. Kinship: have-rel-role-92, ARG1 the person, ARG2 the relative, ARG3 the role. Never use ARG0 for the person.
- Connectives: 但/然而/虽然…但 → but-91 (or contrast-91) with `:ARG1`/`:ARG2`; never contrast-01 or cause-01. 因为/由于/所以 → `:cause`, or have-reason-91 (ARG1 result, ARG2 reason). Do not make 进行/得到/作 light-verb nodes: use the noun's own event (改组-01, 改革-01).
- Role names: `:possessor` (not `:poss`), `:place` (not `:location`), `:companion` (not `:accompanier`), `:instrument` for 用/以/凭 tools and means, `:medium` for languages and channels (以普通话广播, 语言 `:medium-of` 服务), `:manner` for adverbs of an event (全面, 连续, 普遍, 以…名义), `:mod` for 更/亦/又/也/还/同样/均/已经/仍/等. A part is the parent with `:part-of` (各地 `:part-of` 中国, 北部 `:part-of` 加沙); a member uses `:subset-of` (member first). A 3rd-person starting point uses `:source`, a destination without an ARG uses `:goal`, and "except" uses `:subtraction`.
- Named entities: the type must be an English type from the guideline table (organization, company, government-organization, country, city, local-region, road, building, station, language, broadcast-program…), never a Chinese common noun (电视台, 地区, 街, 医院) and never `street`/`place`. Split names by word (`:op1 … :op2 …`), as strings. Languages (普通话, 粤语) are language named entities, and place names are named entities. Do not merge two names into one, and do not put a place into an organization's name.
- Keep classifiers and numbers: `:quant N :unit 量词` (一间, 三套, 7名, 一座, 个). Digits only as constants. Ordinals use `:ord (ordinal-entity :value N)`. Do not drop 该/这 (`:mod`), 各自, 分别, 同时, 同年 (resolve to the year), 「等」 (last op of an and/`:mod`), or 开始/继续 (predicates 开始-01/继续-01).
- Aspect: habitual states or customs (播放, 服务, 实行, 自制, 会撰), activity for 正在/着, performance for completed past events, state for a present state; not process/state for ordinary verbs.
- Temporal direction: (A :before B) means B is BEFORE A, and (A :after B) means B is AFTER A. A past event: (document-creation-time :before e), never (DCT :after e) or (e :before DCT). If A happens first and B later, write (A :before B)… as "B before A", e.g. "建立后实行" → (建立 :after 实行). Every event and every time expression needs a temporal parent (use :contained for a date and its event). Planned or purpose events come after the main event: (计划 :after 售).
- Modal: every event needs a modal parent. An event with :polarity - is full-negative (不设, 不被允许, 拒绝接受). Complements of 计划/申请/要求/呼吁/需要/允许 hang under that predicate (unspecified/partial-affirmative), not under author. 可/能 → neutral-affirmative, with no node for the modal word. A quote or report: (author :full-affirmative speaker) and (speaker :full-affirmative content).
- Coreference: link every repeated mention (including place names, organizations, 车队, 该台, 此限制) to the nearest earlier mention, with the earlier one first. Use `:same-entity` for entities, `:same-event` for events, and `:subset-of` for members. Never self-link. Within a sentence, reuse the node (reentrancy), never `:coref` triples or `:refer-to`. Do not link different events (a second application, or a different plan).

## Skill

- Not-in-PropBank words get `-00`, never `-01`. Words that are in PropBank use their exact entry (限于, 处于, 来自, 位于, 迁至, 购自, 现存, 常用, 惨死, 长达, 印有), not a similar one. Use only roleset arguments: one-argument predicates (不同, 身亡, 有限, 大, 低, 恢复, 惨死) take `:ARG0`; never invent ARG2/ARG3/ARG4. Check PropBank before numbering. If a core ARG fits, don't use `:place`/`:source`/`:manner`.
- Copula 是/为/即是 creates no node: use identity-91 (ARG1, ARG2) for equatives, appositions and 分别是; not 是-01/为-01/`:domain`.
- Titles use have-org-role-92 with ARG1 person, ARG2 organization, ARG3 title. Kinship uses have-rel-role-92 with ARG1 person, ARG2 relative, ARG3 role. Never use ARG0 for the person or -91.
- 但/虽然…但 → but-91/contrast-91 with `:ARG1`/`:ARG2` (not contrast-01). 因为/由于/所以 → `:cause` or have-reason-91 (ARG1 result, ARG2 reason), not cause-01. Light verbs (进行/得到) are not predicates: use the noun event (改革-01).
- Role names: `:possessor`, `:place`, `:companion`; `:instrument` for 用/以 tools; `:medium` for languages/channels; `:manner` for event adverbs (全面, 连续, 以…名义); `:mod` for 更/亦/又/也/还/同样/均/已经/等. `:part-of` with the part as parent; `:subset-of` with the member first. Also `:source`, `:goal`, `:subtraction`.
- Named-entity types are English types from the guideline table (organization, company, country, city, local-region, road, building, station, language…), never Chinese nouns or `street`/`place`. Split names by word and as strings. Languages and place names are named entities. Don't merge names.
- Keep classifiers and numbers: `:quant N :unit 量词`; digits only; ordinals use `:ord (ordinal-entity :value N)`. Keep 该/这 (`:mod`), 各自, 分别, 同时, 同年 (resolve it), 等, and 开始/继续 (as predicates).
- Aspect: habitual for customs and recurring services; activity for 正在/着; performance for completed events; state for present states; not process for ordinary verbs.
- Temporal: (A :before B) means B is before A. Past events: (document-creation-time :before e), never (DCT :after e) or (e :before DCT). If A comes first and B later, write (A :before B) as "B before A", so "建立后实行" → (建立 :after 实行). Every event and time expression needs a temporal parent (date `:contained` event). Planned and purpose events come after the main event.
- Modal: every event needs a modal parent. :polarity - → full-negative. Complements of 计划/申请/要求/需要/允许 go under that predicate (unspecified/partial-affirmative). 可/能 → neutral-affirmative, with no node. A report or quote: (author → speaker → content).
- Coref: link every repeat mention (including place names, organizations, 车队, 该台) to the nearest earlier one, earlier first (`:same-entity`/`:same-event`/`:subset-of`). Never self-link, never link distinct events. Within a sentence, reuse the node, no `:coref` triples or `:refer-to`.
