- Temporal direction: (A :before B) means B is before A; (A :after B) means B is after A. Write past events as (document-creation-time :before E), never (DCT :after E). Sequence of events: earlier event is the child of later: "X后Y" = (X :after Y)... check by reading the triple aloud as "child is before/after parent".
- Every event needs a temporal parent (DCT :overlap for present states/habituals; DCT :before for past; planned/complement events :after their governing predicate; dates :contained the event) and a modal parent (author :full-affirmative by default). Negated events are :full-negative; "可/可能" is :neutral-affirmative; complements of 计划/申请/要求/呼吁/允许/需要 hang under that predicate with :unspecified (or :partial-affirmative for 要求) rather than author. Quoted or reported content hangs under the speaker (author → speaker → content), not author directly.
- Do not invent PropBank sense numbers. Look up every predicate; if the word is not in PropBank use 词-00, and use the original word (e.g. 设有, 迁至, 购自, 改为, 限于, 长达, 写道), not a near synonym. Use only the arguments the roleset actually has (e.g. 不同/身亡/来自/位于/有限 take ARG0; do not default to ARG1/ARG2/ARG3/ARG4). Check the right sense (追溯-02, 加入-02, 限制-02, 要求-02, 居-02, 混-03, 运-02). Where the frame has no role, use non-core roles: :source, :goal, :affectee, :end-state ("改为/转型为X"), :companion (not :accompanier).
- Copulas (是/为/系词, 同位语 "X为Y", "分别是", "长度为") are not events: use identity-91 (:ARG1 theme, :ARG2 equated); existence 有 → exist-91; location without a verb → have-place-91; no 是-01/为-01. Use have-org-role-92 / have-rel-role-92 with ARG1 = the person, ARG2 = organisation/relative, ARG3 = title/role (never ARG0-of; -92 not -91). Apposition of titles/descriptions: identity-91 or :mod.
- Discourse: 但/然而/虽然…但 → but-91 (or contrast-91 with :ARG1/:ARG2); never contrast-01 or cause-01. Reasons/因果 → :cause or have-reason-91 (ARG1 result, ARG2 reason), or the Chinese verb (导致-01).
- Use :possessor (never :poss), :place (never :location), :part-of when the part is the parent (各地 :part-of 中国, 村 :part-of 镇), :subset-of with member first, :medium for languages and channels (以普通话广播, 语言 :medium-of 服务), :instrument for tools (以无人机, 以卫星技术, 用无线电), :manner for adverbial modifiers of events (连续, 普遍, 以…名义), :mod for demonstratives (该/这) and degree-less adverbs (亦, 均, 同样, 还是, 又, 已经, 更); :degree only for adjective intensifiers (非常).
- Never drop content words: keep 该, 各自, 同年, 亦/也, 原, 等, 开始/继续 (as predicates 开始-01/继续-01), 简称 (简称-01 :ARG2 (name …)), 斥资, 内/上/后 locative nouns (node with :op1). Light verbs (进行, 得到) are skipped in favour of the real predicate.
- Quantities: always :quant N :unit 量词 (一间→:quant 1 :unit 间; 三套, 7名, 辆, 座, 种); numbers are digits, never Chinese characters. Ordinals use :ord (ordinal-entity :value N). Superlatives (最大, 最高, 最早): have-degree-91 :ARG2 性质 :ARG3 最 (or :degree 最). Rates: rate-entity-91 :ARG1 count :ARG2 (temporal-quantity 1 天). Times of day: write as a concept node or one string "19:30", never split into :time 19 :30.
- Named entities: type must be an English type from the UMR type table (organization, company, government-organization, local-region, country, city, province, road, station, building, language, person, broadcast-program); never a Chinese common noun as type (电视台, 街, 频道, 组织, 医院, 地带). Language names are language :name; place names (including 中国大陆, 台湾, 卑诗省, 礼部) are named entities. Split names into one :opN per word (and keep 间隔号 as its own op). Do not merge a place into an organisation name (TVBS :place 台湾).
- Coreference: every repeated entity/event (names, places, 该台, 此限制, 这次空袭, 申请, 当局=CRTC) gets a document-level :same-entity / :same-event to the nearest earlier mention, earlier mention first. Never self-links, never link name nodes, never link different applications/plans or distinct quantities. Within one sentence use reentrancy of the same variable, never a :coref triple or duplicate node.
- Aspect: process verbs/habitual practices (播放, 服务, 经常性做法, 程序步骤) → habitual; 正在/着 → activity; completed past → performance; states for copular/descriptive predicates. Event nouns and relations that are real events get :aspect; non-event nouns (暴雨, 流量) do not.
