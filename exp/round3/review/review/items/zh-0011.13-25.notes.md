# zh-0011 第 13–25 句 小结
## gold 的问题
- 并列/选择/对比概念用 :ARG1/:ARG2 而不是 :opN，还常多套一层只有一个子节点的 and：13、15（and-contrast）、16（and、or）、19、21、24、25。
- 角色谓词：-91 没改成 -92，机构职位误用 have-rel-role（14 总统、20 检察长），ARG2/ARG3 写反（14），有空的 have-rel-role-91（18 督抚、19 官员），19 家属用了 ARG4-of。
- 时间表达不写 date-entity：:year 直接挂在事件或 and 上（13、23），民国十三年写成 民国 :year 十三（20），:era 当角色用（24）。
- 把普通名词写成命名实体，或 name 格式不对：13「县」、17「官方」、19「北洋政府时期」；13 柳树/台源的 :name 指向普通概念，23 name 的 :op 是实体节点；名字不按词切分（22 公园）。
- 核心论元错：14 刻 :ARG0 徐世昌、刻 :place（PropBank ARG2）、漏 建 :ARG1 牌坊（13）；21 exist-91 用 ARG0/ARG1，23 有-03 又用 ARG1/ARG2，两套论元号混用；15 用 同-01 :polarity - 代替 不同-01；19 撰 :ARG2 碑文；功能词建了节点（17 才能、18 在、25 并未、轻动词 进行-01）；守节作 :mod 不作事件（13、25）。
- 文档级 temporal：:depends-on 用在事件上（15、17、19、20），18 整句没有 temporal，21 exist-91 没有时间，25 同一事件对 DCT 既 overlap 又 before；14 题写与刻的先后写反。
- 文档级 modal：认为的内容直接由作者断言（24、25），否定事件 full-affirmative（25），允许的补足事件 full-affirmative（19）；21 两个状态、20 惨死缺 modal。共指：:subset-of 方向写反（22、23），连到修饰词而不是中心语（13 s12x4），句内写 coref 三元组（13、15），实体与谓词节点 same-entity（22），泛指与部分写成 same-entity（21）。
- 每句都有 (root :modal author)。对齐有错（14 放上-01 对到「上」，15 两个「形式」对到第2词，23 两个「有」「座」对到同一词），不写条目。

## 系统的问题（s3/r1–r5，同一模型）
- 文档级 :before/:after 方向全反（5 个运行，几乎每个有先后关系的句子，约 30 处）：系统把 (A :before B) 读成「A 在 B 前」。正确是子对父：(A :before B) = B 在 A 之前，如「建在发现之前」写 (发现 :before 建)、过去事件写 (document-creation-time :before 事件)。依据 guideline Part 4-2-2-1（:before = child is before parent）、精简版 5.1。
- 一元谓词的唯一论元写成 ARG1（5 个运行都有，约 8 处：15 不同-01、20 惨死-01/死-01、22 有名-01、25 富有-01）。PropBank 这几个词都只有 ARG0（things which are different / entity described / entity who die / theme），应写 ARG0 或 :ARG0-of。
- 位于-01 作关系从句时中心语写成 :ARG1-of，和处所两个 ARG1（21、22，5 个运行）；应是 (X :ARG0-of (位于-01 :ARG1 处所))，PropBank 位于-01 ARG0 entity described。第13句它们写对了。
- have-org-role-92 照 AMR -91 写：任职者用 :ARG0-of，机构/职位用 ARG1/ARG2 或 ARG2/ARG3 颠倒（r1–r4，14、20）。应为 (人 :ARG1-of (have-org-role-92 :ARG2 机构 :ARG3 职位))，依据 guideline 2.3 表格和 Part 1 例 (4)；只有 r5 写对。
- 不在 PropBank 的词编 -01：奏请-01（5 个运行，18）、撰-01（r1、r3，19）、旌表-01（r4、r5）；应写 词-00（guideline 2.1）。另有 r2、r4、r5 把「撰」换成 撰写-01：概念应用原词。
- 系词「为/是」写成 为-01、为-03、是-01（r1、r2、r4，15、16、24、25），r4 还加了不存在的 ARG2；应转成 identity-91（guideline 2.1：copula 不是事件，转成 2.3 的抽象谓词）。
- 受益者「为 X」写成 ARG2（r3、r4：13 建-01、20 撰写-01），这两个 roleset 没有 ARG2；应写 :affectee（guideline 表 9）。
- 量词省掉（r2、r3、r4 几乎全省，r1、r5 也有，约 12 处：这座、第二任、10 座、11 座）；项目规则：量词保留为 :unit。方位词不建节点（5 个运行：14 牌坊上/石匾上，21 地区内，22 公园内）；项目规则要建，训练数据写法 (上 :op1 机身)（chinese_umr-0001 第46句）。
- PropBank 有整词义项的复合词拆开：常用-01 → 用-01 + :frequency 常（16），惨死-01 → 死-01 + :manner 惨（20）（r1、r2、r4、r5）。中文名字不按词切分，整串放进一个 :op1（柳树村、台源镇、金门县、邱良功母节孝坊、林氏贞孝坊、二二八和平纪念公园；r1–r4 常见，r5 较少）；guideline 2.2 按词切分，且「县/村」已由类型表达。
- :degree 用在修饰事件的副词上（更、普遍、真正；r1、r2、r3、r4）；项目规则 :degree 只用于性质的强化/弱化，事件上的副词用 :manner 或 :mod。
- 旧拼写 :poss（r1–r4，16、19、24、25）应为 :possessor；共指三元组后出现的在前（r2、r3、r5 常见），guideline 5.3 先出现的在前。漏标：r3、r4 有整句没有文档级 temporal（15、16、22、r4 还有 17），系统常漏补足事件或从句事件的 modal/temporal（18 查访、上报；21 位于）。
- 零散：r2 把引号字符串当概念（14「节励松筠」、16「钦旌节孝」）；r5 给「可能」建节点（16，情态词不建节点）；r1 用 :place 表示行政区划包含（13、22，应 :part-of）；r4 写自指共指 (X :same-entity X)（14、21）。
- 规则冲突（待负责人定）：17「必须」——guideline 2.1/Part 3-1-3-3 说情态助动词不建节点，训练数据有 必须-01 作谓词（chinese_umr-0001 第25、26句，-0005 第33句）；各方都记 open。
