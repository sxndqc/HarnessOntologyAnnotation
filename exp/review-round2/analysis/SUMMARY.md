# 第二轮审阅总结（48 篇文档，7 种语言）

这一轮把 Codex 第二次运行的结果全部逐句审阅了一遍：48 篇文档、1,546 句，其中 30 篇是 shared task 的测试集（中文 15、英语 5、捷克语 5、意大利语 1、拉丁语 1、Arapaho 2、Navajo 1）。审阅者是 Claude Opus 子代理，不是人；下面所有"gold 应改""系统正确"都是模型的判断，还没有经过人工确认。

系统名：`s0` 是 baseline（guideline 只有一句话、没有工具、整篇一次标完，只跑测试集），`s1f` 是完整 guideline、无工具，`s3` 是精简 guideline 加全部查询工具，`a2` 是逐句标加全部工具；`r1`、`r2` 是同一设定的两次运行。

## 主要结论

1. **有工具的两个设定明显好于无工具的，baseline 最差，这在每种语言上都成立。** 测试集比较点上的正确率：s0 约 60%，s1f 约 72%，s3 约 84%，a2 约 81%。s3 的"错"只有 1.6%，是所有设定里最低的。
2. **按审阅的判断，gold 在比较点上的正确率（56%）低于所有系统，包括 baseline。** 但比较点只取各标注不一致的地方，gold 和系统一致的地方不计入，所以这个数字不能读成"gold 有一半是错的"。原 gold 对修订版 gold 的 AnCast 分数在 83（中文）到 94.5（拉丁语）之间，这才是 gold 实际改动幅度的量度。
3. **gold 的问题集中在文档级标注和中文。** 中文每句平均判定应改 4.9 处，其他语言是 0.6 到 2.2 处。文档级的时间、模态、共指三类里，gold 的正确率只有 31% 到 39%（全部文档）。
4. **gold 修订以后所有系统的分数都上升，有工具的设定升得最多。** 测试集上 AnCast Comprehensive：s0 从 39.5 升到 42.6，s1f 从 45.8 升到 51.5，s3 从 48.9 升到 56.1，a2 从 50.5 升到 57.0。官方指标 juːmæʧ 也是全部上升（见下表）。
5. **Arapaho 和 Navajo 上系统和审阅都更弱。** Arapaho 的 gold 正确率最高（87%），系统最低（s3 约 62%，s0 约 35%）。这两种语言的审阅只能依靠词素释义和训练数据的先例，把握比其他语言低。

几点观察：

- s3 和 a2 谁好因语言而异：英语、意大利语上 a2 略好；中文、捷克语、拉丁语、Navajo 上 s3 好。拉丁语上 a2（约 66%）比无工具的 s1f（约 77%）还低。
- a2 的弱项是文档级模态和共指（全部文档上约 67–71% 和 76%，s3 是约 89% 和 88%）；逐句标注时看不到全篇。
- baseline 的弱项是义项（约 45%）和文档级时间（约 30%）：没有 guideline 就不知道 UMR 时间关系的方向约定，整篇写反。
- 两次运行之间的一致度：同一设定的两次运行在有分歧的点上约 69–78% 相同，不同设定之间约 39%。

## 读这些结果时要注意的地方

- **审阅者是模型。** 条目里的 high 表示有 guideline 或词表的明确依据，mid 表示审阅者认为应改但有判断成分，low 只是提示。修订版 gold 包含 high 和 mid。要用修订版做正式评测，应先在审阅页面里人工过一遍（接受或拒绝每条方案，然后导出）。
- **比较点上的正确率偏向系统。** 审阅者拿 gold 和 8 份同源的系统标注比较，系统之间一致而 gold 不同的地方容易被判成 gold 的问题。gold 修订后系统分数上升，有一部分是这个原因。
- **baseline 的重复习惯计数不完全统一。** s0 全篇重复的同一种习惯（例如时间关系方向写反），在大多数文档里只在第一次出现处计一次，之后记为"定不了"；zh-0028、zh-0032 两篇做得早，是每处都计，所以这两篇里 s0 的"错"偏多。新审的非中文文档里，s0 是和其他系统一起逐条判的，体系性差别同样只在第一次出现处记。
- **s0/r1 的 Navajo 输出有约 80 行词形被改坏**（`’a’` 变成 `’s4a’` 之类）。Codex 交回的原始输出里就是这样，是那次运行自己造成的，计入它的错误。
- **en-0008 有泄漏。** 完整版和精简版 guideline 里都有这篇的句子，精简版第 1 节直接包含第 3 句的 gold 标注。en-0008 上的分数（尤其 s1f、s3、a2）不能和其他英语文档直接比。
- **zh-0017 的 AnCast 打不了分**（gold 里 `:ratio-of 330` 让打分器出错），和上一轮一样，表里没有这一篇。
- **gold 的版本。** zh-0026、zh-0036 用 UMR 2.2 的 test-gold（UMR 3.0 的 zh-0026 每一句文档级标注都有括号不匹配）；捷克语 3 个文件修了 4 处 `/` 后缺空格的格式问题；13 篇旧中文测试文件审的是上一轮给的在审版本，不是发布版。
- **还没定的规则。** `:subset-of` 的方向、`individual-person`、指示词加量词的写法，以及 Navajo 训练数据里 `have-role-91`、`have-quant-91` 用 ARG0/ARG1 而 guideline 写 ARG1/ARG2。这些地方审阅者没有改 gold，或只提了 low。完整清单见"错误类型"一页末尾。
