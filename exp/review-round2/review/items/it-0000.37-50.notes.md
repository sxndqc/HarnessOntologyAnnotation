# it-0000 第 37–50 句 小结

## gold 的问题

- 否定句只写 `:modal-strength …-negative`，不写 `:polarity -`：第 37（两处 non）、41（mostrare、dare）、42（addestrare）、49（superare）句；同一份 gold 第 1、41（consenso）、56 句又写了，前后不一。
- 事件漏 aspect / modal-strength 或 aspect 取值错：40 commuovere 两者都缺；47 sospendere 两者都缺；40 volere 标 performance（应 state）；46 照片 mostra 标 activity（应 state）。
- 参与者角色分配不当：心理事件 commuovere 用 actor/theme（40），言语行为 ordinare 反而用 experiencer/stimulus（41）；comporre 的构成成员 soldati 标 :actor（38）；exist-91 的存在物一贯标 :ARG1（37，另见 11、81），与 guideline 的 :ARG2 不合。
- 结构性遗漏或颠倒：42 funzionare 没挂主体 sistema；45 「un numero record di reti」头和修饰语颠倒、Bundesliga 挂在 numero 上；43 年份 2014 只挂在 rinnovare 上，和 2013 挂法不一致；43 漏了 inoltre。
- guideline 约定没有照做：39 轻动词 commettere un errore 没去掉；42 让步（anche con…）写成 :condition；48 类别归属用 identity-91（应 have-role-91）；40 talmente 用 :extent、proprio 用 :manner。
- 复数名词漏 `:refer-number plural`，有量词时尤其如此：38 soldati（molti）、43 mercati（数词）、50 persone（diverse）；第 23 句同类情况又标了，前后不一。
- 实体类型：38 Balcani 作 geo-political-entity（gold 自己第 18、28 句用 world-region）；38 achemenide 作 ethnic-group 不准。城市 human-settlement、一级行政区 country-partition 是全篇一贯写法，未判错。
- 非标准写法：40 用 `:modal-predicate` 在图里指模态父节点（同第 62、99 句），47 把「inizi」动词化为 iniziare 又不给 aspect；50 giorno `:temporal-of presiedere` 方向不对。
- 对齐（不写条目）：gold 常把节点对到冠词、介词上（38 soldato→da、40 bellezza→dalla、50 candidare→dell'、50 persona→di），命名实体的 name 节点多为 0-0。
