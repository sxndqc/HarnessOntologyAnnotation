# zh-0004 第 1–17 句 小结

## gold 的问题

- 补足语 / 转述 / 目的的 modal 一律 author full-affirmative：试图→改造（3）、提倡→合为、认为→拥有、进步（10）、打算→合成（11）、可化解、谈判（13）、能会变成（17）；目的事件见证（5）、壮大（8）也挂 author。
- 转述没有说话人 conceiver：称（10）、告诉（13，还给了 partial）、指（15，连「指」节点都没有）、解释（17）。
- temporal 方向或关系错：目的 / 计划内容写成 :overlap（见证 5、壮大 8、合成 11、15）；(阻止 :after 合作) 方向反（3）；同一对事件同时 :after 和 :overlap（7）；事件作时间词的父节点（1）；以无关事件为参照（5 到←第 3 句继承）。
- 事件缺 modal / temporal 父节点或 aspect：主句 identity（1）、饰演（2）、落成（5）、多个 identity-91（1、2、9）、解释无 aspect（17）；非事件「固有」进了文档级（2）；无效 modal 值 `:State`（13）。
- 抽象谓词论元编号错：have-91 用 ARG0/ARG1（2）；identity-91 用 :ARG0（9 两处、10 两处）；have-reason-91 不在 guideline（10、17）。
- PropBank 编号 / 论元：阻止-02（应 -01，3）、需要-03（应 -01，17）、改掉-00（应 -01，15）、建立 :ARG2 处所（应 :place，17）；漏核心论元：收看 ARG0/ARG1（4）、壮大 ARG0（8）、回到 ARG0（13）、重过 ARG0（15）、拥有 ARG0 是悬空节点（10）、注入 ARG0 写成博士（应为格拉斯，16）。
- 漏词：仅（7）、也（14）、又、这、大量能源（17）、利用（12）、阴谋的领属者（3）。
- 结构错误：:part 方向反（1）；and 两个 :op1（5）；重复的出演节点（2）；认为 :ARG0 写成概念为变量名的节点（13）；即-02、implicit-argument 等虚构节点（17）；:subtraction 挂在实体上（2）。
- 普通量词当 :unit：名（9）、场（13）、个（14、15、17）；副词用 :mod（成功 3/9、极力 10）。
- coref：连错节点（3 博士连到「人」、11 琼斯等人连到「博士和琼斯」、15 带到 same-entity 继续、16 戴立克连到戴立克人），漏连（9 格拉斯、12 博士、17 这些人类），不连最近先行语（9、14），句内写 coref（13）。
- 对齐错误多（两个节点对同一词，如 2 出演、10「人后」、17「十多分钟」），按说明未写条目。全篇用 individual-person 而系统用 person，两者都按 ok 处理，未写条目。

## 系统的问题

- s1f（无工具）两次：义项靠猜，PropBank 错得最多——吸引-01、称-01、当-01、协助-01（12、16）、指-01、合-01、重过-01，带不存在的论元（成功-01 ARG1、合成 ARG2、余下 ARG2、为主 ARG2、死/落成/失踪 ARG1）；用 :poss、:location 这类非 UMR 角色；s1f/r2 多出 present-reference / past-reference、`root :depends-on` 常量，还把后文事件都挂在第 5 句的 1930 年下。
- s3 两次：论元编号大多对，但都把「系列3」标成 :quant 3（1），都用 :concession 表示「除了……外」（2），合成 :ARG2 / :goal（s3/r1、s3/r2，8、11），都漏了「到」（15）；s3/r2 have-org-role-92 用在没有组织的身份上（9、17）。
- a2（逐句）两次：结构和 modal 层次最接近 guideline（补足语挂 unspecified / partial，转述引入 conceiver），但名字里带书名号（1 a2/r2；3、7 两次都带），「戴立克人格拉斯」整串当人名（2 a2/r2），戴立克人当成 person 名字（8 a2/r2），用 :end-state，:mod 已，目的事件、谈判仍挂 author full-affirmative（5、8、13）。
- 共同点：gold 的补足语 modal、目的事件的 :after、漏掉的核心论元，6 个系统大多都标对了；系统之间的分歧主要在角色名和义项（s1f）以及 conceiver 的挂法上。
- r1 与 r2 的差别：同一设定内基本是个别词上的随机差异（实体类型、:mod / :manner、aspect），没有固定方向；s1f 两次都错在同样的义项上。
