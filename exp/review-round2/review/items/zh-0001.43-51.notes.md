# zh-0001 第 43–51 句 小结

## gold 的问题

- 文档级 modal 一律 `partial-affirmative`，且层次错乱：平铺直叙的转述内容（43 检查/发现、44 公布/停放、45–47 全句、48、50、51 开除/进入）都写 partial；被拒绝的事件写成 partial-affirmative（48 派发）；命令、目的辖下的未然事件挂 author 而不是 unspecified（49 勾引/传播/削弱、50 还债、51 引诱）；实体当 conceiver（47 飞机、49 报纸并列节点→绝症/专门）；同一对 author→报纸 重复 4–6 条、强度互相矛盾（44、46、48–51）。
- 跨句共指大面积漏标：43 整句无 coref（拿破仑、芯片、头骨、发现），45 漏「这个消息」，44/49/50/51 国名、人名（美国、地球、布什、世界新闻周报）不连。
- 句内重复实体建成两个节点：43 拿破仑、50 美国；把变量名当概念（48 任 :ARG0 `(s48s / s48i3)`、49 传播 :ARG2 `(s49s / s49x13)`）。
- 部分关系方向反：44 一面 `:part` 月球、火山口拆成 `口 :part 火山`，50 头版 `:part` 时代商报。
- 命名实体：书名号写进 name（44、49、50、51），月球标 planet（44、47），「前苏联」作 country-region 且「前」进名字（44、45），「布什总统」整体作名字（51），世界新闻周报名字含「美国」（49）。
- PropBank / 抽象谓词编号：have-org-role-91（43、50）、exist-91 用 ARG0/ARG1（46）、送进-01 两个 ARG1（48）、下令 :ARG1 美女（49）、置-01（应 置于-01，50）、「无法」作 :manner 而不加 polarity（43）。
- temporal：绝对日期挂 DCT 并用 :before / :overlap 连事件（44、47），30 年代没进时间树（48）；`(DCT :after 引用)` 方向反（48、49），49 有自环 `(报导 :before 报导)`；未然 / 目的事件写 overlap 而不是 after（45、49、50、51）。
- 结构：49「据…报导」做成与「传」并列的 据-02；51 把「而幕后操作者可能是民主党」并进「因为」的原因；46、47 but-91 论元顺序与「然而 / 但」相反；漏补控制 / 目的从句的 ARG0（48 派发、49 传播、50 还债）；事件节点缺 aspect（48 驻、50 庞大）。
- 惯例性差异（不提修改）：普通量词保留为 :unit（枚、条、架、名）、individual-person、方位词「上 / 中」建节点。第 45–47 句 gold 自造 `implicit-predicate` 作 :quote（只给 low）。对齐残留很多（变量对到错误的词），按说明不写条目。

## 系统的问题

- s1f（无工具）两次：PropBank 编号靠猜——称-01、背向-01、染-01（染色）、送-01、消失 :ARG1、得知 :source、下令 :ARG2；部分关系方向写反（43 头骨、44 一面、46 机身/机翼、50 头版）；用 AMR 旧名 `:poss`、非 UMR 角色 `:location`；每句加 `(author :full-affirmative null-conceiver)`；文档时间用 past-reference 代替 DCT；句内共指另建节点再写 :coref（43、46、51）。
- a2（逐句）两次：文档级 modal 几乎全挂 author，转述层（说话人、报纸、照片）丢失，命令 / 目的事件也写 full-affirmative（49、50、51）；「引用报导」常把 引用 降为 :manner（49、50/r1）；`:mod 曾 / 已 / 结果`；曾任-00、身染-00 等不查已有义项。
- s3 两次：论元和 modal 层次最好（49 一路 unspecified、48 拒绝 :full-negative 派发）；r1 有 company（环球网、新华网）、报导 :ARG0 引用者、报导为根；r2 把 50 句「置于 / 跟进」并入报导内容、背向 :ARG0 火山口。
