# cs-0000 第 90–100 句 小结

## gold 的问题

- 体系：通用参与者角色、裸词元不带框架号（第 90 句各记一条，两边都 ok）；文档级 gold 没有标注，未比较。
- 省掉主句的致使动词，改用 :cause：přinutit（92，丢了「被迫」，fix mid）、vyvolat（95）、vést / způsobit（96）；第 96 句还把崩溃/干预直接挂到破产上，丢了因果链第一环（fix mid）。
- 变量、挂接错误：svrhnout 的受事指向起义本身（95，high）；Izabela 的 :name 挂在 have-rel-role-92 上（98，high）；prokonzul 与 César 另立节点不相连（100）。
- 漏词：konvertovaných（94）、Tyto（99）、označit 的 aspect 和 modal-strength（90）、neznamenalo 的 :polarity -（92）；单复数 refer-number 时有漏标（91 Štěpán、93 Fiorello、94 Židé、96 banka）。
- 未然/非断言事件一律 full-affirmative：目的从句 soustředit-se（91）、被否定的 vyřešit（92）、need 的目标 získat（97）、假设条件句 přijmout / mít-nárok（98）、尝试的目标 nastolit 与决定的补语 provést / napadnout（99）；naznačovat 的补语 opustit（91，low）。
- 抽象谓词编号：have-role-91 的类别写成 :ARG2（91、100，本文件 48、50、51 句是 :ARG3）；have-org-role-91（93，按规则改 -92，high）；znamenat 写成 identity-91（92）。
- 角色分配：intervence 的银行写成 :actor（96）；opustit soutěž 用 :source（91）；pokus 的内容用 :result（99）；potřebovat 挂成整句的 :reason（97）；:duration 用于「13 世纪期间」（90）。
- 其他格式：名词词元未还原 osadníci（97）；固定说法 rána z milosti 按字面拆开（97，系统同）；jaro 另套 date-entity（99）；:era 写成 (BCE) 节点（100，本文件一贯）；Kingdom of France 用 state 类型（99）；比较级用非标准的 more-than 且丢了 mnohem（98）。
- 第 100 句与第 30 句原文相同，gold 两处写法完全不同（have-role-91 / :result）。
- 对齐（不写条目）：命名实体的类型节点、name 节点多对到 0-0 或词组，mechdiff 因此出现「无节点」行（90 Apulie、92 Rakušan、98 Izabela 等）。

## 系统的问题

- 所有系统：命名实体名字照抄屈折形式（Marenga、Rakušany、Palmě、Linaresem、Ludvíka、Césarovo、Francouzského），只有 gold 写原形；a2/r2 常把专名写成普通名词（Apulie、Marengo、Itálie、Linares、Jindřich）。
- s0、s1f 两次：全篇只标复数 refer-number，单数不标（s0/r2 连复数也常漏）；全篇用旧角色 :poss；s1f 对间接转述加 :quote（91、94）、照搬 :modpred（97、99）。
- s0 两次：反身动词丢 se（soustředit、vzdát、zhroutit、rozhodnout）；have-org-role / have-rel-role 编号错位（ARG0 本人、-91，91、93、98）；s0/r2 多建情态动词 moci 节点（91）。
- s3、a2：最接近捷克文训练数据（:clausal-marker nicméně、:effect、:regard týkat-se、desítka :mod）；modal 强度多数给得对。但 a2 的 aspect 偏差较多（soustředit-se state、zůstat / potřebovat performance、activity），s3/r2、a2 用 :possessor / :mod 硬连「počet Židů」。
- modal：带 guideline 的系统对目的、需要、决定、条件句的补语多给 neutral / partial / unspecified，比 gold 好；s1f/r2、a2/r1 第 98 句假设条件仍给 full。
- 句内共指：s0、s1f 在第 100 句用 :coref 连 prokonzul 与 César，违反「句内用重入」；s3、a2 用重入，正确。
- r1 与 r2 之间没有固定方向的差别，主要差在角色名词怎么重写（have-role-91 / have-org-role-92）和 aspect。
