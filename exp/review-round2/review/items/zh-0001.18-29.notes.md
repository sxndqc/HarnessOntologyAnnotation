# zh-0001 第 18–29 句 小结

## gold 的问题

- 引号里的新闻标题整句当作命名实体名字：publication 的 :op 里包含「」和动词，内容全丢（第 18 句 苏联复制…、19 句 美国买通…、20 句 12位参议员是外星人）；刊名的 :op 带书名号《》（第 22、27、29 句）。
- 引述内容的 conceiver 写成 author：少算（21）、虚构（23）、警语里的抛开 / 不信任（28）、故事里的饿 / 看成（26）；同一事件挂两个互相矛盾的 author 强度（26 有）。
- 用自造或不在 guideline 里的抽象谓词代替标准角色：have-reason-91 代替 :purpose / :cause（19、25、26、29），have-temporal-91（22），have-org-role-91（25），identity-91 连接新闻和内容（20、26、28），implicit-predicate（23）。
- 情态动词「必须」立成 必须-01 节点（25、26）；否定「从不」丢 polarity，modal 也成了 full-affirmative（27）。
- 普通量词立 :unit：篇（18、19、20、23）、个（21、26）、位（26）；第 19 句还在「也」下重复挂 :unit 篇 :quant 1。

- 修饰语挂错：纷纷 挂小报 :manner（22）、不明就里 挂引用 / 报导（29）、写-01 挂在副词「曾」下（26）。
- 定语形容词立事件（显著-01 18、常见-01 24）；typifying 修饰用 :topic / :place（外交 19、八卦 22、新闻事件 22、网络谣言 29）。
- aspect：明显的事件标 state（批评 / 道 / 开玩笑 21、所言 23、告诉 25、节食 / 看成 26）；拿着 标 performance（26）。
- 漏标：甚至（20）、仍（22）、这些（22）、仍然（24）、满足的 ARG0「他们」（25）、加注 / 报导 的 ARG0（22、28）。

- 对齐错误较多（两个节点对到同一词：复制-01 对到标题 19、新闻对到刊名、报导 / 新闻 / 读者 重复对齐），按说明没有写成条目。
